# 从退租到起租（lease-gap）

换租时旧房到期和新房起租对不上：填两边月租、旧房到期日、违约金、续住价、新房能起租的日子和搬家要几天，把每一种「哪天交旧房钥匙 × 哪天新房起租」都算一遍，看提前退、到期退、续住几天各多花多少，哪天最省。

- 单页静态应用：`index.html` + `core.js`（计算）+ `ui.js`（界面），不联网、不收集数据，条件只存在本机 localStorage。
- 模型：比「到期当天交钥匙、同一天新房起租」多花多少 = 新房早起租天数 × 新日租 − 提前退天数 × 旧日租 + 违约金 + 续住天数 × 续住价 + 住外面晚数 × 每晚价 + 多搬一次。日租 = 月租 ÷ 30 或 月租 × 12 ÷ 365。整数精确计算。
- 测试：`node --test tests/core.test.cjs`；独立 Python 参考实现 `tests/ref.py`（date + Fraction 逐日穷举）生成 `tests/ref.json`（300 组）。
- 默认数字是虚构示例；合同怎么写以合同为准。
